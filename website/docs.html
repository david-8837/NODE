Quick Start

NODE studio works in two environments: as an installed Windows desktop application (with native Smart Actions and HUD overlay) and in any Chromium browser (Chrome or Edge) via WebHID over HTTPS or localhost.

  1. Launch NODE studio on your computer.
  2. Connect your Grid Macro 1 via USB-C.
  3. When prompted, click Connect and authorize the 0xFEED:0x6001 Raw HID keyboard interface.
  4. Studio will immediately read your active device layers and synchronize the keymap in real time.

Device Connection & Safety

The configurator uses a connection gate: if no pad is connected, editing is disabled to ensure no out-of-sync writes can occur.

  • Auto-Backup: Before writing any change to device memory, Studio captures a local backup snapshot. You can revert to this backup anytime in Settings.
  • Disconnect Protection: If the USB cable is unplugged while you are customizing keymaps, your profiles remain completely intact in local storage.
  • Simulation Mode: You can toggle Simulation Mode in Settings to test macros, shortcuts, and app launches using your computer keyboard without physical hardware.

Configuring Keymaps (3×3 Matrix)

Each of the nine keys can be individually assigned with a single keycode, keyboard chord, media control, or custom action:

  • Basic Inputs: Alphanumerics, navigation arrows, function keys (F1–F24), and number pad keys.
  • Shortcuts: Multi-key chords (e.g. Ctrl + Shift + S, Alt + F4, Win + V).
  • Icons: Pick custom icons from Tabler or Lucide icon catalogs to display directly on key tiles.

Rotary Encoder (Dial)

The top-left rotary encoder supports three distinct hardware trigger events per layer:

  • Clockwise (CW): Standard default is Volume Up, Zoom In, or Timeline Forward.
  • Counter-Clockwise (CCW): Standard default is Volume Down, Zoom Out, or Timeline Rewind.
  • Encoder Press: Built-in push switch (GP11), commonly used for Mute, Zoom Reset, or Play/Pause.

Hardware Layers & Profiles

The QMK firmware supports 4 hardware layers (Layer 0 through 3). You can create multiple profiles (e.g., Coding, Video Editing, Gaming, Streaming) with up to 4 layers each.

Assign Layer Cycle or a momentary layer shift to any key to switch layers instantly with muscle memory.

Smart Actions & Multi-Actions

Host-assisted actions take your macropad beyond standard keyboard HID:

  • App Launching: Select any installed Windows application or Start Menu shortcut to launch in one press.
  • Text Insertion: Paste boilerplate code, terminal snippets, or canned email replies without typing errors.
  • Web Links: Open your favorite dashboards or repositories in your default browser.
  • Multi-Action Gestures: Set different actions for Tap, Double-Tap, and Hold on the exact same key.

Cheat Sheet HUD Overlay

In the Windows desktop app, press the designated Cheat Sheet key to toggle a transparent, click-through acrylic HUD overlay showing all current layer shortcuts directly over your active games or IDE.

Firmware & UF2 Flashing

The Grid Macro 1 uses an RP2040-Zero controller running QMK with VIA v13 Raw HID protocol.

  1. Unplug the macropad.
  2. Hold down the BOOT button on the controller while plugging the USB-C cable back in.
  3. A mass-storage drive named RPI-RP2 will appear in Windows File Explorer.
  4. Drag and drop the official grid_macro_1_via.uf2 firmware onto the drive.
  5. The drive unmounts automatically and reboots into configured studio mode.
