[:: ACTIONS FIELD GUIDE ::]

Make each press do more.

Build repeatable keyboard macros, assign different jobs to a single button, and trigger text, apps, or web pages from your macropad.

In this guide

Recorded Actions Multi-Actions Smart Actions Assign and test
01 / RECORDED MACROS

Actions

An Action records a sequence of keyboard input and replays it when you press its assigned macropad key. It works well for repeated shortcuts, text entered as keystrokes, and predictable key sequences.

Example · Format a file in your editorRecord Ctrl + Shift + P, type Format Document, then press Enter. One button runs the command-palette sequence whenever the editor is focused.
  1. Open Keymap, choose Action, then select New Action.
  2. Name the action and start recording. Press the keys in the order you want them replayed, then stop recording.
  3. Review the sequence. Use Advanced Mode to add keys manually, adjust delays, or insert a key the recorder missed.
  4. Save the action, then assign it to a key on the macropad.
Recording tipSome applications capture or intercept shortcuts, so a key may not appear in the recording. Check the sequence before saving and add missing keys in Advanced Mode.
02 / GESTURE SHORTCUTS

Multi-Actions

A Multi-Action gives one physical key up to four gesture bindings. Assign a different key, shortcut, or saved action to each gesture that you need.

Example · One music control keyTap to play or pause, double-tap to skip to the next track, and hold to go to the previous track. Keep the gestures you use and leave the others empty.
On TapPress and release once.
Double TapPress twice quickly.
On HoldKeep the key pressed.
Tap + HoldTap, then press and hold.
  1. Choose Multi-A and create a new Multi-Action.
  2. Enter a binding for each gesture you want to use; leave unused gestures empty.
  3. Set the tapping term. This is the time window used to distinguish a single tap from a double tap.
  4. Save it, assign it to a key, and try each configured gesture at a comfortable pace.
Gesture timingWhen a double tap is configured, the app may wait briefly before firing On Tap so it can tell whether a second press follows. A longer tapping term gives more time for the second press, but makes single taps feel less immediate.

Multi-Action gesture recognition is handled by the desktop app during use. The app and device must remain connected for host-side behavior.

03 / HOST ACTIONS

Smart Actions

Smart Actions run a specific task from one press. Pick the type that matches what you need:

Text · Reuse a responseType a saved status update, email sign-off, or code snippet into the focused app.
Cmd · Check a projectRun a command such as git status without retyping it. This is off by default; enable Allow terminal commands via Smart Actions in Settings only for commands you trust.
Web · Open a work pageLaunch a frequently used issue board, dashboard, or project URL in your default browser.
App · Start your editorLaunch an installed Windows application shortcut, such as VS Code, with one press.
  1. Choose Smart-A, select New Smart Action, then choose Text, Cmd, Web, or App.
  2. Enter the text, command, URL, or installed app required by that type.
  3. Save the Smart Action and assign it to a macropad key.
Desktop requirementSmart Actions use the running Windows desktop app to type text, launch apps, and run commands. Browser mode supports device configuration, but does not provide those native Windows integrations.
04 / PUT IT TO WORK

Assign and test

  • Connect your Grid Macro 1, open Keymap, and select the target key.
  • Choose the saved Action, Multi-Action, or Smart Action from the mapping options, then apply the assignment.
  • Test it in the intended application. For text insertion, place the cursor in the target field first.
  • If nothing happens, confirm the assignment is saved, the desktop app is running, and any required Smart Action setting is enabled.
