TROUBLESHOOTING

Frequently Asked Questions

Pad not detected by WebHID or Studio?

Ensure your USB-C cable supports data transfer (some charging-only cables will not expose the USB data lines). When using Google Chrome or Microsoft Edge, ensure you grant access to the 0xFEED:0x6001 HID device in the browser prompt.

Windows SmartScreen warning on install?

The prebuilt Windows binaries are currently self-distributed and unsigned. Click "More info" and then "Run anyway". For full verification, all releases include verifiable SHA-256 build logs built directly on GitHub Actions runners.

Do Smart Actions follow the device to another PC?

Hardware keys, rotary encoder directions, and layer assignments live on the physical QMK device. Host-assisted Smart Actions (such as specific Windows app launching) and custom profile labels live in local browser storage, and can be exported as portable JSON.

How do I reset to factory firmware?

Hold the BOOT button while plugging in the USB cable to mount the RPI-RP2 drive, then copy over a fresh grid_macro_1_via.uf2 build from the Releases page to restore default settings.
