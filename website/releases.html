v1.1.12 LATEST
November 2026

Rotary Sensitivity & Step Multiplier

  • Added configurable Rotary Dial Step Multiplier ($1\times$ to $5\times$) in Settings for accelerated volume control, timeline scrubbing, and brush sizing in creative software.
  • Seamlessly integrated step multiplier into simulation and desktop event dispatch.

Rotary Rotation Guardrails & Smart Inverse Pairing

  • Enforced physical guardrails on Clockwise (CW) and Counter-Clockwise (CCW) rotary actions, preventing multi-actions with delays, shell commands, and app launchers from choking input queues.
  • Added dynamic Action Drawer category tab filtering: Multi-A and Smart-A tabs are restricted with tooltips when rotation is selected, while center Dial Press remains 100% unrestricted.
  • Implemented smart inverse pairing: assigning an incremental action (e.g. Volume Up, Zoom In, Next Tab, Undo) automatically sets its opposite counterpart on the reverse direction.

Frosted Dark Acrylic Cheat Sheet HUD

  • Upgraded the floating keymap HUD to a frosted dark acrylic glass backdrop (rgba(14, 14, 18, 0.86) with 28px blur and translucent key fills) for complete legibility over bright or yellow backgrounds.
  • Eliminated window edge subpixel clipping of the outer outline border via a 2px inset buffer.

Seamless Connection Gate Titlebar

  • Integrated a sleek, full-width dark titlebar on the Device Connection Gate matching the native Windows window controls.

Downloads & Packages

  • Windows Setup (x64): NODE.studio-1.1.12-x64.exe — Official NSIS installer for 64-bit Windows 10 & 11 with auto-update support.
  • QMK Firmware: grid_macro_1_via.uf2 — Pre-compiled VIA Raw HID firmware for Waveshare RP2040-Zero.

v1.1.11
November 2026

Active Window Profile Auto-Switching & Rules Engine

  • Implemented background active window tracking using Win32 API hooks via koffi.
  • Added Custom App-to-Profile Mapping Rule Editor in Settings with process and window title regex filters.
  • Added automatic installed application picker to populate rules with a single click.

Keycap Legend & Color Personalization

  • Added custom primary text and subscript sub-legend personalization per keycap.
  • Added 7-swatch keycap tint color palette with real-time hardware canvas previews.
  • Preserved legend and color styling across profile import, export, and JSON backups.

Acrylic Cheat Sheet HUD Global Hotkey

  • Added system-wide OS global hotkey registration (default: Ctrl+Alt+M) to summon the HUD over any fullscreen game or app without stealing window focus.
  • Added hotkey customization presets and 1-click overlay preview test in Settings.

Community Profile Hub & Visual Tutorial

  • Launched Community Profile Sharing Hub with 1-click install for Blender, VS Code, Photoshop, and DaVinci Resolve.
  • Added comprehensive Interactive Visual Tutorial page (tutorial.html) with 10 feature deep-dives and hardware architecture guide.

Architecture & Code Quality

  • Decomposed App.tsx into modular custom hooks (useTipRotation, useInstalledApplications, useDeviceNotifications, useKeymapHistory, useAppSettings).
  • Purged 980 lines of dead code and pruned 22 unreferenced dependencies; migrated animations to native Motion v12.
  • 100% automated test suite passing across 57 test files (496 tests) and 10 E2E Playwright specs.
